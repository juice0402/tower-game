# のびのびタワー

ビルを建てて育てるタワー経営シミュレーション。ドット絵の小さな人たちがエレベーターを待ったり、オフィスで働いたり、ホテルに泊まったりします。

## 芯にしていること
1. エレベーターのやりくり（待ち時間との戦い）
2. 入居者が増えて、★が上がっていく（★3まで）
3. 人がちょこちょこ動くのを眺める
4. オフィス・住まい・飲食店・お店・ホテル・駐車場など、施設の組み合わせ
5. 地下を掘ったり、上へ上へ伸ばしていく

## 遊び方
- 1Fにロビー → エレベーターでつなぐ → オフィスや住まいを建てる
- 待ち時間が長いと満足度が下がり、出ていってしまう
- ★2：人数300人＋警備室 ／ ★3：人数1000人＋医務室＋駐車場＋ホテル10室
- スマホ（縦持ち）とPCのブラウザで遊べる。セーブは自動、書き出しでほかの端末へ移せる

## 作る人むけ
- `npm test` … しくみのテスト
- `npm run build` … `dist/index.html`（1つのファイルにまとめたもの）を作る
- 開発中は `index.html` を静的サーバーで開く（`src/main.js` をそのまま読む）
- バランスの数字は `src/config.js` にまとまっている
